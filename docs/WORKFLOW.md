# תהליך עבודה

## איפה עובדים ובאיזה מודל

| משימה | איפה | מודל |
|---|---|---|
| תסריט, מטאפורות, ניסוח בעברית, משוב על הרעיון | צ'אט / Project | Sonnet |
| בניית התבנית או סצנה חדשה מאפס | Claude Code | Opus |
| תיקונים קטנים: טקסט, צבע, תזמון | Claude Code | Sonnet |
| משהו שנתקע ולא מצליח להיפתר | Claude Code | Opus |

בקיצור: כשמדובר במילים, עובדים בצ'אט. כשמדובר בקבצים, עוברים לקוד. Opus שמור לבנייה ולתקלות.

## שלבי סרטון
1. **תסריט** (צ'אט, Sonnet): 60–90 שניות, מטאפורה אחת מרכזית. לבדוק מול אנשים אוטיסטים או איש מקצוע.
2. **קובץ תוכן** (Claude Code, Sonnet): להעביר את התסריט ל-`content/<name>.json`.
3. **צורות חדשות** (Claude Code, Opus): אם המטאפורה דורשת צורה שאין עדיין ב-`Shape.tsx`.
4. **קריינות**: הקלטה עצמית או ElevenLabs. הקובץ נכנס ל-`public/audio/`.
5. **תזמון וכתוביות** (Claude Code, Sonnet): להתאים את `seconds` של כל סצנה לקריינות.
6. **רינדור ופרסום**: `npm run render:<name>`, ואז commit ו-push.

## חיסכון בטוקנים
- Project בצ'אט עם הבריף הקבוע (סגנון, צבעים, קהל).
- שיחה נפרדת לכל שלב.
- לבקש תיקון של סצנה ספציפית, לא בנייה מחדש של כל הסרטון.
